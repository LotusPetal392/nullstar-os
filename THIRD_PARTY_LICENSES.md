# Third-Party Licenses

This document tracks third-party software, source code, assets, firmware, fonts,
and other materials distributed as part of NullStar OS.

## Cargo dependencies

NullStar OS depends on Rust crates resolved through Cargo. These dependencies are
not relicensed under the NullStar OS license; each dependency remains subject to
its own license terms. The exact dependency versions are recorded in
`Cargo.lock`, and their declared licenses can be reviewed through their package
metadata and source distributions.

## Repository contents

At the time this document was added, the repository was intended to contain
project-authored source code and documentation together with ordinary Cargo
dependency metadata. No third-party artwork, firmware, fonts, binary blobs, or
vendored source trees are intentionally distributed in the repository unless
listed below.

## Individually tracked components

No individually tracked third-party components are currently listed.

When third-party material is added directly to the repository, update this file
with:

- the component or asset name and version;
- its upstream source;
- its copyright holder or attribution notice;
- its license and a link or path to the corresponding license text; and
- notes describing local modifications, if any.

Do not add material unless its license is compatible with the project and the
repository preserves every required copyright, attribution, source, and license
notice.
